# 🎬 ALVIN - Plateforme de Gestion de Films et Séries

Plateforme web complète inspirée de TMDb avec synchronisation automatique des données.

## 📋 Caractéristiques

- ✅ Backend Laravel 12 complet
- ✅ Synchronisation automatique TMDb
- ✅ API REST + API V2 personnalisée
- ✅ Panel d'administration complet
- ✅ Frontend moderne (Vue.js)
- ✅ Authentification JWT
- ✅ Docker complet
- ✅ Redis Cache
- ✅ Tests automatisés

## 🚀 Quick Start

```bash
git clone https://github.com/bjdjdu8378/Alvin.git
cd Alvin
docker-compose up -d
```
